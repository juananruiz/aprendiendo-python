Colecciones [ ] ( ) { }

Las cuatro estructuras de datos base de Python, cara a cara: qué son, cómo se comportan y qué funciones usa cada una. Guárdala y vuelve cuando dudes.

Lista [] Tupla () Conjunto { } Diccionario {k:v}

De un vistazo

Cada una en detalle

list [ ]

Colección ordenada y mutable. La navaja suiza: para casi todo lo que "cambia".

frutas = ["pera", "uva", "pera"]
frutas[0]        # 'pera'  (índice)
frutas[-1]       # 'pera'  (desde el final)
frutas[0:2]      # ['pera','uva'] (slicing)
  • .append(x)añade x al final
  • .extend(it)añade todos los de un iterable
  • .insert(i,x)inserta x en la posición i
  • .remove(x)borra la 1ª aparición de x
  • .pop([i])saca y devuelve (último por defecto)
  • .sort()ordena in-place
  • .reverse()invierte in-place
  • .index(x)posición de x
  • .count(x)cuántas veces aparece x
  • .copy()copia superficial

Comprehension: [x*2 for x in nums if x>0]

tuple ( )

Ordenada pero inmutable. Para datos fijos: coordenadas, registros, claves de dict.

punto = (3, 4)
x, y = punto     # desempaquetado
solo = (5,)         # ¡la coma la hace tupla!
nada = (5)          # esto es un int, no tupla
  • .count(x)cuántas veces aparece x
  • .index(x)posición de x

Solo tiene 2 métodos: al ser inmutable, no puede añadir ni borrar. Sí admite índice, slicing e in.

Truco: son hashables, así que sirven como clave de un dict o elemento de un set (una lista no).

set { }

Sin orden y sin duplicados. Para pertenencia rápida y álgebra de conjuntos.

a = {1, 2, 2, 3}   # -> {1, 2, 3}
vacio = set()        # ¡{} es un dict vacío!
2 in a              # True — búsqueda O(1)
  • .add(x)añade un elemento
  • .discard(x)borra x si está (no falla)
  • .remove(x)borra x (falla si no está)
  • .pop()saca uno cualquiera
  • a | bunión
  • a & bintersección
  • a - bdiferencia
  • a ^ bdiferencia simétrica
  • .issubset(b)¿a está contenido en b?

Inmutable: frozenset(...) es la versión fija (sirve de clave/elemento).

dict {k:v}

Pares clave→valor. Claves únicas y hashables. El caballo de batalla de Python.

edad = {"ana": 30, "leo": 27}
edad["ana"]         # 30  (KeyError si no existe)
edad.get("x", 0)    # 0   (seguro, sin error)
  • .get(k,d)valor de k, o d por defecto
  • .keys()vista de las claves
  • .values()vista de los valores
  • .items()pares (clave, valor)
  • .update(d2)fusiona otro dict
  • .pop(k)saca y devuelve el valor de k
  • .setdefault(k,d)lee o inicializa k
  • .popitem()saca el último par insertado

Recorrer: for k, v in edad.items():

Lo que sirve para todas

len(col)

Número de elementos. Funciona en las cuatro: len([1,2]), len({1,2})...

x in col

¿Está x dentro? Rapidísimo en set y dict (busca en claves); lineal en list y tuple.

for x in col

Itera los elementos. En dict recorre las claves por defecto.

Conversión

list(t), tuple(l), set(l) (¡quita duplicados!), dict(pares).

Comprehensions

Cada tipo tiene la suya: […], {…} (set), {k:v …} (dict). La tupla usa tuple(… ).

sorted / sum / min / max

Funciones que aceptan cualquier iterable y devuelven un resultado nuevo sin modificar el original.

Trampas típicas

{} no es un set

{} crea un dict vacío. Para un set vacío usa set().

(5) no es una tupla

Un solo elemento necesita la coma: (5,). Sin ella es solo el número entre paréntesis.

Mutable como valor por defecto

def f(x=[]) comparte la misma lista entre llamadas. Usa x=None y créala dentro.

Copiar no es asignar

b = a apunta a la misma lista. Para copiar de verdad: a.copy() o a[:].

El set desordena

Convertir a set quita duplicados pero pierde el orden. Si lo necesitas, ordénalo después.

Modificar mientras iteras

Añadir o borrar de una colección dentro de su propio for da errores raros. Itera sobre una copia.
