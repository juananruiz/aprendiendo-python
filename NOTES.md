# Notas de trabajo

## Preferencias del usuario

- **Idioma**: español para explicaciones, código en español cuando es didáctico
- **Estilo**: prefiere práctica sobre teoría — aprender haciendo
- **Referencias**: usa el libro "Comprender los algoritmos" como ancla para las lecciones de algoritmia
- **Profundidad**: le gusta entender el porqué, no solo copiar código
- **Errores**: prefiere que le señales errores en su código como herramienta de aprendizaje
- **Zona de confort**: sabe lo básico de Python, ha implementado algunos algoritmos, pero quiere escribir Python más idiomático

## Formato de lecciones

- Lecciones cortas (15-20 min cada una)
- Cada lección debe terminar con un ejercicio práctico
- Relacionar cada concepto nuevo con algoritmos del libro cuando sea posible
