# Misión: Dominar Python para algoritmos y automatización

## Meta final

Poder leer, escribir y modificar scripts en Python con fluidez para:

1. **Implementar y entender algoritmos** clásicos siguiendo el libro *"Comprender los algoritmos"* de Aditya Y. Bhargava
2. **Automatizar tareas** del día a día (fuera del desarrollo web, que ya cubro con PHP/React)
3. **Tener base sólida** para incursionar en análisis de datos, scripting, o lo que surja
4. **Pensar en programación funcional** — un cambio de aires deliberado. En PHP me muevo en modo OOP; quiero que Python sea el sitio donde entreno el otro paradigma: funciones puras, inmutabilidad, composición, pipelines de datos sin bucles explícitos

## Por qué esto importa

Ya tengo experiencia en desarrollo web con otras tecnologías. Python me interesa como herramienta de propósito general — para resolver problemas que no son web: procesar datos, automatizar tareas repetitivas, implementar algoritmos desde cero, y entender cómo funcionan las cosas por debajo.

El objetivo funcional tiene una motivación aparte: no es que Python "obligue" a ello, es que **yo elijo** entrenar ese músculo aquí porque en el día a día profesional (PHP) no lo ejercito. Es contraste intencionado, no una necesidad del lenguaje.

## Qué significa "dominarlo"

- Escribir Python idiomático sin pensar en la sintaxis
- Poder implementar cualquier algoritmo del libro sin mirar la solución
- Sentirme cómodo con la stdlib y el ecosistema de paquetes
- Tener criterio para elegir la estructura de datos correcta
- Saber resolver un problema con un pipeline de funciones (`map`/`filter`/`reduce`, comprehensions, generadores) antes de recurrir por inercia al reflejo OOP de PHP

## No-objetivos

- No busco ser desarrollador web en Python (para eso ya tengo PHP/React)
- No me interesa el machine learning profundo ni la ciencia de datos por ahora
- No necesito certificaciones ni cursos formales
