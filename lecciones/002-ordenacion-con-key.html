Ordenación avanzada con sorted() y lambda

El segundo ingrediente para generar rankings automáticamente

sorted() — lo básico

nums = [3, 1, 4, 1, 5, 9]
sorted(nums)                    # → [1, 1, 3, 4, 5, 9]
sorted(nums, reverse=True)     # → [9, 5, 4, 3, 1, 1]

sorted() siempre devuelve una nueva lista. No modifica la original.

El parámetro key

key recibe una función que transforma cada elemento antes de comparar.

palabras = ["manzana", "pera", "kiwi", "sandía"]
sorted(palabras, key=len)       # → ["kiwi", "pera", "manzana", "sandía"]

Funciones lambda

Una lambda es una función anónima de una sola expresión:

lambda x: x[1]       # devuelve el segundo elemento de x
lambda x: -x         # devuelve el negativo de x (para orden inverso numérico)
lambda x: x["nota"]  # el valor de la clave "nota" de un dict

Equivalente a:

def extrae_nota(candidato):
    return candidato["nota"]
Esta lección es también donde vas a entrenar la Pista 4 — Programación funcional del ROADMAP: una lambda es una función de primera clase, y key= es exactamente pasar una función como argumento a otra función.

Casos prácticos para matching

Ordenar candidatos por puntuación (orden descendente)

candidatos = [
    {"nombre": "Ana",     "nota": 85},
    {"nombre": "Carlos",  "nota": 92},
    {"nombre": "Beatriz", "nota": 78},
]

ranking = sorted(candidatos, key=lambda c: c["nota"], reverse=True)
# → [{"nombre": "Carlos", "nota": 92}, {"nombre": "Ana", "nota": 85}, ...]

Ordenar destinos por preferencia del candidato

preferencias = {"Ana": ["Madrid", "Barcelona", "Valencia"]}
# Ya están ordenadas. Si vienen desordenadas con puntuaciones:
puntuacion_destinos = {"Madrid": 10, "Barcelona": 8, "Valencia": 6}
destinos_ordenados = sorted(
    puntuacion_destinos.items(),
    key=lambda d: d[1],
    reverse=True
)
# → [("Madrid", 10), ("Barcelona", 8), ("Valencia", 6)]

Varios criterios (estabilidad en empates)

candidatos = [
    {"nombre": "Ana",     "nota": 85, "edad": 30},
    {"nombre": "Carlos",  "nota": 85, "edad": 28},
    {"nombre": "Beatriz", "nota": 78, "edad": 32},
]

# Desempate: nota descendente, luego edad ascendente
sorted(candidatos, key=lambda c: (-c["nota"], c["edad"]))
El truco de (-c["nota"], c["edad"]): al devolver una tupla, Python compara primero el primer elemento y solo desempata con el segundo. El signo - invierte el orden solo de ese criterio — útil cuando quieres nota descendente pero edad ascendente a la vez (un único reverse=True invertiría los dos).

list.sort() vs sorted()

  • lista.sort() — ordena in-place, devuelve None. Solo funciona en listas.
  • sorted() — devuelve una nueva lista. Funciona con cualquier iterable.
Importante para Gale-Shapley. Vas a necesitar generar rankings automáticamente a partir de datos numéricos. Acostúmbrate a escribir lambdas que extraigan el campo que te interesa y a usar reverse=True para orden descendente.
