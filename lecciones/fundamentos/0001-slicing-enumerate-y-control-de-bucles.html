Slicing, enumerate y control de bucles

Tres herramientas de Python que harán tus algoritmos más limpios

Ya implementaste búsqueda binaria y ordenamiento burbuja — bien. Ahora vamos a refinar cómo escribes esos bucles. Estos tres patrones aparecen en cada algoritmo que implementes.

1. Slicing — rebanar listas

El slicing te permite extraer sublistas sin bucles manuales. Es una de las características más potentes de Python y aparece constantemente en algoritmos de divide y vencerás (capítulo 4 de tu libro).

La sintaxis: lista[inicio:fin:paso]

ExpresiónResultadoExplicación
lista[1:4][20, 30, 40]Desde índice 1 hasta 4 (excluido)
lista[:3][10, 20, 30]Desde el inicio hasta 3
lista[3:][40, 50, 60]Desde 3 hasta el final
lista[-2:][50, 60]Últimos 2 elementos
lista[::2][10, 30, 50]Cada 2 elementos
lista[::-1][60, 50, 40, 30, 20, 10]Lista invertida

Referencia completa en 03-listas.html

En algoritmos

En Quicksort (capítulo 4), partirás listas en dos usando slicing. En Búsqueda binaria, aunque tú usaste índices con while, también podrías pensar en términos de "sub-lista izquierda" y "sub-lista derecha". 

# Ejemplo: partir una lista por la mitad
lista = [2, 5, 8, 12, 16, 23, 38, 45]
medio = len(lista) // 2
izquierda = lista[:medio]   # [2, 5, 8, 12]
derecha  = lista[medio:]    # [16, 23, 38, 45]


# Obtener el último elemento sin saber su longitud
ultimo = lista[-1]  # 45


# Obtener todos menos el primero y el último
medio = lista[1:-1]  # [5, 8, 12, 16, 23, 38]
Cuidado: el slicing crea una copia de la sublista. En listas grandes, hacer lista[:] repetidamente tiene coste O(n). Para algoritmos de búsqueda binaria, es mejor usar índices como ya haces.

2. enumerate — índice y valor a la vez

Cuando necesitas la posición y el elemento en un bucle, enumerate evita el patrón feo de range(len(lista)). 

# Sin enumerate (el patrón que debes evitar):
for i in range(len(lista)):
    print(i, lista[i])

# Con enumerate (Python idiomático):
for i, valor in enumerate(lista):
    print(i, valor)

# Puedes empezar en otro número:
for i, valor in enumerate(lista, start=1):
    print(f"{i}: {valor}")   # empieza en 1 en vez de 0

En algoritmos

Tu script de burbuja tiene este error (línea 26): 

lista[1], lista[i + 1] = lista[i + 1], lista[i]  # ✗ usa índice fijo 1

Debería ser lista[i] en vez de lista[1]. Este error es menos probable si usas enumerate — porque el índice te lo da el propio bucle.

# Así sería más difícil equivocarse:
for i, valor in enumerate(lista[:-1]):
    if valor > lista[i + 1]:
        lista[i], lista[i + 1] = lista[i + 1], valor

3. break, continue y else en bucles

break — salir del bucle

Ya lo usas en tu búsqueda binaria. Rompe el bucle inmediatamente.

continue — saltar iteración

Salta al siguiente ciclo sin ejecutar el resto del bloque.

# Sumar solo números pares
numeros = [3, 8, 2, 7, 10, 5]
suma = 0
for n in numeros:
    if n % 2 != 0:
        continue
    suma += n
print(suma)  # 20 (8 + 2 + 10)

for/else — el bloque sorpresa

El else en un for se ejecuta si el bucle terminó sin encontrar un break. Es como un "premio por no haber roto el bucle".

# Buscar si hay un número par en la lista
numeros = [3, 7, 9, 11]
for n in numeros:
    if n % 2 == 0:
        print("Encontrado par:", n)
        break
else:
    print("No hay ningún par")  # ← esto se ejecuta

En tu búsqueda binaria, podrías eliminar la bandera numero_encontrado usando este patrón:

# En vez de usar una bandera...
numero_encontrado = False
while ...:
    if numero == lista[posicion]:
        numero_encontrado = True
        break
    ...

if numero_encontrado:
    print("Encontrado")
else:
    print("No encontrado")


# ...puedes hacer esto:
while ...:
    if numero == lista[posicion]:
        print("Encontrado")
        break
    ...
else:
    print("No encontrado")  # solo si el while terminó sin break
