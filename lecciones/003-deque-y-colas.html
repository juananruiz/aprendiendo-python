Colas con collections.deque

La estructura que lleva la cuenta de quién sigue libre

Qué es una cola (FIFO)

Una cola es como la fila del pan: el primero que llega es el primero en ser atendido. First In, First Out (FIFO).

En Gale-Shapley, los participantes que aún no tienen asignación definitiva esperan en una cola. Cuando un participante es rechazado, vuelve a la cola. Cuando uno acepta provisionalmente, sale de la cola.

list como cola — problema

Podrías usar una lista:

cola = []
cola.append("Ana")     # entra al final → ["Ana"]
cola.append("Carlos")  # → ["Ana", "Carlos"]
siguiente = cola.pop(0)  # "Ana" — pero pop(0) es O(n) 😱

pop(0) es lento porque Python tiene que desplazar todos los elementos restantes una posición. Para conjuntos pequeños no se nota, pero es ineficiente.

collections.deque — la solución

from collections import deque

cola = deque()
cola.append("Ana")        # → deque(["Ana"])
cola.append("Carlos")     # → deque(["Ana", "Carlos"])
siguiente = cola.popleft()  # → "Ana", O(1) — instantáneo
popleft() es O(1). Siempre.

Operaciones útiles

cola = deque(["Ana", "Carlos", "Beatriz"])

cola.popleft()        # saca por la izquierda: "Ana"
cola.append("David")  # añade por la derecha
cola[0]               # mira el primero sin sacarlo: "Carlos"
len(cola)             # cuántos quedan
"Carlos" in cola      # comprueba si está (O(n), pero útil)

En Gale-Shapley

# Participantes que aún no están asignados (o han sido rechazados)
pendientes = deque(todos_los_participantes)

while pendientes:
    participante = pendientes.popleft()
    destino = siguiente_preferencia(participante)
    if destino_acepta(participante, destino):
        # el participante queda asignado provisionalmente
        # (sale de la cola)
        ...
    else:
        # vuelve a la cola a intentar con el siguiente destino
        pendientes.append(participante)
Alternativa: conjunto de pendientes. A veces se usa un set en vez de deque cuando no importa el orden exacto de procesamiento. Pero deque es más natural: refleja la idea de «ir atendiendo uno por uno».

Ejercicio práctico

Simula la fila de propuestas

En Gale-Shapley, los candidatos libres esperan en una cola y van proponiendo uno por uno; si son rechazados, vuelven a la cola. Vas a simular esa dinámica a pequeña escala: operaciones básicas de deque, una simulación de ronda de propuestas con destinos de plazas limitadas, y una variante que ordena la cola por prioridad antes de empezar.
