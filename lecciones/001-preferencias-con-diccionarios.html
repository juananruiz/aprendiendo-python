Preferencias modeladas con diccionarios

La estructura de datos que sostiene todo el algoritmo de matching

El algoritmo Gale-Shapley trabaja con listas de preferencias. Cada participante ordena a los miembros del otro conjunto de mejor a peor. En Python, la forma natural de modelar esto es con diccionarios.

Estructura básica

preferencias_candidatos = {
    "Ana":     ["Madrid", "Barcelona", "Valencia"],
    "Carlos":  ["Barcelona", "Valencia", "Madrid"],
    "Beatriz": ["Valencia", "Madrid", "Barcelona"],
}

Cada clave es un candidato, y el valor es una lista con sus destinos ordenados de más preferido a menos preferido (posición 0 = el más deseado).

Preferencias desde ambos lados

En Gale-Shapley, ambos conjuntos tienen preferencias. Las plazas/destinos también ordenan a los candidatos: 

preferencias_destinos = {
    "Madrid":    ["Ana", "Beatriz", "Carlos"],
    "Barcelona": ["Carlos", "Ana", "Beatriz"],
    "Valencia":  ["Beatriz", "Ana", "Carlos"],
}

De puntuaciones a preferencias

En tu caso real no hay preferencias declaradas: tienes puntuaciones. La preferencia de un destino por un candidato es directamente su nota. La preferencia del candidato por los destinos puede calcularse combinando sus intereses personales con la nota mínima exigida por cada plaza.

Para generar el ranking automáticamente:

candidatos = {"Ana": 85, "Carlos": 92, "Beatriz": 78}

# Ranking: ordenados de mayor a menor puntuación
ranking = sorted(candidatos.items(), key=lambda x: x[1], reverse=True)
# → [("Carlos", 92), ("Ana", 85), ("Beatriz", 78)]

Acceso rápido a la posición en la preferencia

Para comprobar si A prefiere a B sobre C, necesitamos saber el índice de cada uno en la lista de preferencias: 

def prefieres(preferencias, quien, candidato_a, candidato_b):
    """True si 'quien' prefiere a 'candidato_a' sobre 'candidato_b'"""
    lista = preferencias[quien]
    return lista.index(candidato_a) < lista.index(candidato_b)
list.index() es O(n) — para conjuntos pequeños es perfecto. Para miles de elementos convendría un diccionario índice, pero eso lo veremos más adelante.
Resumen
  • Las preferencias se modelan como dicts donde cada clave tiene una lista ordenada
  • Ambos conjuntos tienen preferencias
  • Las puntuaciones numéricas se convierten a ranking con sorted() y key=
  • La función prefieres() es la operación básica del algoritmo

Ejercicio práctico

Genera los dos rankings desde datos brutos

Tienes un proceso selectivo con 5 candidatos y 3 destinos. Cada candidato tiene una puntuación y unas preferencias personales; cada destino tiene una nota mínima y un número de plazas. Tu tarea: generar los dos rankings (candidatos→destinos y destinos→candidatos) a partir de esos datos brutos, filtrando a los candidatos que no llegan a la nota mínima de cada destino.
